Part D. Pure logic (no React)
4) Create src/components/puzzle/p1-rl.ts
   - export type NodeId = string
   - export type Node = { x:number; y:number; kind:"room"|"junction"|"deadend"; neighbors:NodeId[] }
   - export type Maze = { start:NodeId; goal:NodeId; nodes:Record<NodeId, Node> }
   - export function edgeKey(from:NodeId, to:NodeId): string
   - export type Memory = Record<string, { correct:number; incorrect:number }>
   - export function atGoal(id:NodeId, maze:Maze): boolean
   - export function isDeadEndNode(id:NodeId, maze:Maze): boolean   // kind === "deadend"
   - export function shouldStop(id:NodeId, prev:NodeId|undefined, maze:Maze): boolean
       // stop at rooms, and at junctions where options excluding backtrack > 1
   - export function nextChoice(
         nodeId:NodeId,
         prev:NodeId|undefined,
         maze:Maze,
         memory:Memory
     ): { next:NodeId; choiceEdge:string }
       // choose among neighbors (excluding prev only if there are other options)
       // softmax over score = (correct - incorrect), small epsilon so every option has non-zero chance
   - export function updateMemory(
         memory:Memory,
         edge:string,
         label:"correct"|"incorrect"
     ): Memory
       // returns a new memory with incremented counts

Part E. React component
5) Create src/components/puzzle/P1ReinforcementMaze.tsx
   - "use client"
   - Props: { onSolved: () => void }
   - Load maze from p1-maze.json.
   - State:
       current: NodeId
       prev: NodeId | undefined
       lastEdge: string | null
       memory: Memory
       phase: "stopped" | "deciding" | "moving"
       status: string  // text for aria-live
   - Render:
       - A responsive 16:9 container with the background image /assets/images/maze/Ship_Maze.png
       - Glitch sprite absolutely positioned at (x%, y%) for the current node
       - Control panel with two buttons:
           [ Correct decision ] [ Incorrect decision ]
         These are enabled only when phase = "stopped" and lastEdge != null. Clicking them updates memory for lastEdge.
       - aria-live="polite" region for status
   - State machine:
       - On mount: set current = maze.start, prev = undefined, phase = "stopped"
       - If atGoal(current) -> onSolved() and do not continue
       - When phase = "stopped": after 250 ms, set phase = "deciding"
       - When phase = "deciding":
           - If shouldStop(current, prev, maze) is false, auto-advance without a pause
           - Else compute nextChoice(...), store lastEdge, set phase = "moving", start animation
       - Movement: animate from prev node to next node with CSS transform over 400 ms
           - After animation: set prev = old current, current = next, phase = "stopped"
           - If isDeadEndNode(current, maze) is true, pause 250 ms then reset to start (preserve memory)
           - If atGoal(current) is true, call onSolved()
   - No timers visible in the UI. Do not import any useTimer.
